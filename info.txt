Step 5B: Audit fields, soft delete, paging helper and base repository

This part adds four things so every later feature gets them for free:

Automatic audit fields. Saving a new row fills in CreatedAt and CreatedBy, and editing fills in UpdatedAt and UpdatedBy, with no manual code.
Soft delete. Remove(...) never deletes a row. It flips IsDeleted instead.
A pagination helper, for the search, sort and page screens.
A base repository, so each feature doesn't repeat the same database code.
