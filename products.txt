         │
         ▼
 2. 📑 MODAL INITIALIZATION & FORM FILL
    └── ProductFormModal.jsx opens:
         ├── If Add Mode ──> Sets empty state (EMPTY)
         └── If Edit Mode ──> Pre-fills form state with existing product values
         │
         ▼
 3. ✍️ USER SUBMIT & FRONTEND VALIDATION
    └── User fills fields and clicks "Save":
         ├── Runs validate() function
         ├── If errors found ──> Stops execution & highlights invalid fields
         └── If valid ──> Constructs payload { ...form, standardPrice: Number(...) } all this in productmodelform.jsx
         │
         ▼
 4. 🔌 FRONTEND SERVICE LAYER
    └── productService.js triggers the appropriate API call:
         ├── Create ──> POST /api/products (createProduct)
         └── Edit   ──> PUT /api/products/{id} (updateProduct)
         │
         ▼ (HTTP Request over network)
 5. 🛡️ BACKEND SECURITY GATEWAY
    └── Program.cs Middleware Pipeline:
         ├── UseAuthentication() ──> Validates JWT Token
         └── UseAuthorization() ──> Checks [Authorize(Roles = Roles.OfficerOrAdmin)]
             (Returns 403 Forbidden if user is a standard Employee)
         │
         ▼
 6. 🎯 BACKEND CONTROLLER LAYER
    └── ProductsController.cs receives request:
         ├── [HttpPost] Create(ProductRequest request)
         ├── [HttpPut("{id:int}")] Update(int id, ProductRequest request)
         └── ASP.NET DataAnnotations validate ProductRequest ([Required], [Range])
         │
         ▼
 7. ⚙️ BACKEND SERVICE & BUSINESS LOGIC
    └── ProductService.cs executes logic:
         ├── Trims input and uppercase SKU (e.g., "SKU-001")
         ├── Runs EnsureUniqueAsync() ──> Checks if SKU already exists
         │    └── If duplicate SKU ──> Throws ConflictException (400/409)
         └── Maps DTO to Product Entity model
         │
         ▼
 8. 📦 REPOSITORY LAYER (The Missing Link! 🔍)
    └── _products.Query() (which comes from IRepository<Product>):
         ├── Acts as an abstraction layer between Business Logic and EF Core

         │
         ▼
 9. 🗄️ DATABASE INTERACTION LAYER & ORM

         ├── Runs .ApplySort() and Expression Projections
         └── Executes ToPagedResultAsync() ──> Runs SQL with OFFSET & FETCH NEXT
             (Brings ONLY the required 10 records from SQL Server)
         │
         ▼ (JSON Response over network)

         │
